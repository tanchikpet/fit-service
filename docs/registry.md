# Реестр сайтов FIT SERVICE

Рабочая версия: https://fit-requests-kaiten-api-production.up.railway.app/app/registry

Реестр перенесен в FIT Requests на Railway. Вход через существующий Telegram-аккаунт FIT Requests. Данные находятся в PostgreSQL. Подключение GitHub и токен для редактирования больше не нужны.

PM добавляет и редактирует записи, принимает/отклоняет найденные адреса, запускает проверки. Приглашенные сотрудники могут просматривать реестр. Сохранены основной реестр, архив, поиск, история HTTP-проверок и список «На проверку».

Проверки выполняются сервером ежедневно после 12:00 Новосибирска и вручную. Напоминания о сроках акций идут PM через текущего Telegram-бота FIT Requests. Старый workflow GitHub больше не проверяет адреса и не отправляет напоминания.

Файлы data/registry*.json в main оставлены как исторический снимок. Не редактировать их для изменения рабочего реестра. Исходная реализация и данные сохранены в истории Git.

Подробности: [серверный реестр](https://github.com/tanchikpet/fit-service/blob/feature/kaiten-sync-backend/fit-requests-server/REGISTRY.md).

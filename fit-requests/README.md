# FIT Requests — личный рабочий прототип

Прототип внутреннего инструмента PM для управления запросами, проектами, сроками, демо и отчётностью. Размещён в отдельной директории существующего репозитория, без изменения корневых файлов.

## Что работает

- Дашборд с метриками по задачам
- Реестр заявок, поиск и фильтры
- Создание и редактирование заявки, карточка задачи
- Локальное сохранение данных в браузере (localStorage)
- Проекты и прогресс
- Временная шкала планирования по условным датам
- Просмотр задач со статусом «Демо»
- Три шаблона отчёта с генерацией и редактированием текста, копирование
- CSV-экспорт списка заявок
- Адаптивная вёрстка

## Ограничения и безопасность

- **Это не корпоративная система и не подключение к Kaiten.** Все первоначальные данные — вымышленные демонстрационные примеры.
- Данные сохраняются только в локальном хранилище конкретного браузера. Нет синхронизации, резервного копирования, серверной БД, совместной работы и авторизации.
- Репозиторий публичный. Не добавляйте реальные персональные или внутренние сведения, токены и API-ключи.
- Наличие поля ссылки на Kaiten не означает API-синхронизацию.
- Отчёты — текстовые черновики. PDF/DOCX, согласованные версии, права и архив не реализованы.
- Демо-Гант строится по локальным датам без оценок загрузки и зависимостей.
- Тестовая версия не предназначена для хранения конфиденциальной рабочей информации.

## Запуск

Откройте `index.html` из директории `fit-requests` в браузере либо опубликуйте эту папку на статическом хостинге. Внешняя сборка и пакетный менеджер не требуются.
